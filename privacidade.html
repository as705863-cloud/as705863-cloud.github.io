Política de Privacidade

Última atualização: 18 de novembro de 2026.

O aplicativo Bibliatododia usa os serviços de API do YouTube apenas para que o dono do canal envie, atualize e agende vídeos no próprio canal.

Dados acessados

Com a sua autorização via Google OAuth, o aplicativo acessa somente as permissões necessárias para gerenciar os vídeos do seu canal. Os tokens de acesso ficam guardados apenas no computador do dono do canal.

Uso e compartilhamento

Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Serviços do YouTube e do Google

Ao usar o aplicativo, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

Revogar acesso

Você pode remover o acesso a qualquer momento em myaccount.google.com/permissions. Depois disso, os tokens guardados deixam de funcionar e podem ser apagados.
